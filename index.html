AI Approach Comparison

Evaluating Prompt-Based Grounding vs Programmatic Structured JSON Verification

Active: Approach 2 (Structured JSON + Verification)

Approach 1: Prompt-Based Grounding

Standard
Calculated Metrics → LLM Prompt → Business Digest
  • Simple implementation without complex parsing layers
  • Relies on LLM internal adherence to prompt context
  • Higher risk of hallucinated or subtle numerical drift
  • Difficult to programmatically audit individual claims
Recommended

Approach 2: Structured JSON + Verification

Verified
Metrics → LLM → Structured JSON → Programmatic Verification → Final Digest
  • Extracts claims into structured JSON objects
  • Programmatically verifies numerical values against ground truth
  • Zero unsupported or hallucinated numbers enter final digest
  • Full mathematical auditability and tolerance checking

Evaluation Matrix

Evaluation Category Approach 1 (Prompt-Based) Approach 2 (Structured + Verified)
Numerical Accuracy Moderate (85-90%) 100% Guaranteed
Unsupported Claims Possible (Unchecked) 0% (Blocked)
Programmatic Verification None Automatic Execution
Consistency & Schema Variable prose output Deterministic JSON Schema
Implementation Complexity Low Moderate
